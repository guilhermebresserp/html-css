# html-css

# | PORTUGUÊS / PORTUGUESE |

 Curso de JavaScript do CursoemVideo

O curso é estruturado em 5 módulos sequenciais, indo do absoluto zero até a criação de layouts modernos e responsivos. Abaixo está o detalhamento dos assuntos abordados em cada um dos módulos:

Módulo 1: Conceitos Básicos e Primeira Página Web
História e Funcionamento da Web: Como a internet funciona, servidores, domínios, hospedagem e a diferença entre HTML, CSS e JavaScript.

Preparação do Ambiente: Instalação e configuração do editor de código (VS Code) e extensões úteis.

Sintaxe e Semântica do HTML5:

Estrutura básica de um documento HTML (<!DOCTYPE>, <html>, <head>, <body>).

Parágrafos, quebras de linha, símbolos e emojis.

Hierarquia de títulos (<h1> a <h6>).

Mídias e Formatação:

Inserção de imagens (<img>), favicon, áudios e vídeos (internos e hospedados no YouTube/Vimeo).

Formatação de texto (negrito, itálico, destaques, citações e código fonte).

Listas ordenadas, não ordenadas e de definição.

Links e Âncoras: Criação de links internos, externos e links para download.

Introdução ao CSS3: Primeiros passos com estilos inline, internos e externos.

Módulo 2: Design, Cores, Tipografia e Modelo de Caixas
Fundamentos do Design para Web:

Psicologia das cores, harmonização e ferramentas de paletas de cores.

Representação de cores em CSS (Hexadecimal, RGB, HSL).

Tipografia:

Seleção de fontes e uso de fontes externas (Google Fonts e arquivos locais @font-face).

Alinhamento, tamanho e peso de texto.

Seletores e Pseudo-classes:

Seletores por classe (.), ID (#) e elementos.

Uso de pseudo-classes como :hover, :visited, :active e pseudo-elementos.

Modelo de Caixas (Box Model):

Conceitos de margin, padding, border e outline.

Diferença entre elementos inline e block-level.

Grouping tags (<main>, <header>, <nav>, <article>, <section>, <footer>).

Projeto Prático: Criação de um site completo estilizado (Site sobre a história do mascote do Android).

Módulo 3: Imagens de Fundo, Tabelas e Projetos Avançados
Imagens de Fundo e Efeitos:

Propriedades de background-image, background-position, background-repeat e background-size.

Técnica de paralaxe (parallax scrolling) usando puramente CSS.

Tabelas em HTML/CSS:

Estrutura correta e semântica de tabelas (<table>, <thead>, <tbody>, <tfoot>, <tr>, <th>, <td>).

Mesclagem de células utilizando colspan e rowspan.

Estilização de tabelas grandes e efeito zebra striping.

Tornando tabelas responsivas para telas menores.

Projetos Práticos:

Projeto Cordel (site com efeito paralaxe).

Criação de tabelas completas e dinâmicas.

Módulo 4: Formulários, Iframes e Responsividade (Mobile First)
Iframes (Quadros em Linha):

Uso da tag <iframe> e incorporação de conteúdos externos com segurança.

Formulários Web:

Criação de formulários com a tag <form>.

Tipos de campos de entrada (<input> do tipo text, password, email, number, date, color, range, file, etc.).

Elementos avançados: <select>, <option>, <datalist>, <textarea>, <fieldset> e <legend>.

Validação básica com HTML5.

Design Responsivo e Media Queries:

Conceito de Mobile First (desenvolver primeiro para celular e depois adaptar para telas maiores).

Uso de @media para adaptar layouts a diferentes resoluções e orientações de tela.

Projeto Prático:

Projeto Redes Sociais (menu interativo simulando a tela de um smartphone com telas dinâmicas via iframe).

Módulo 5: Layouts Modernos (Flexbox e CSS Grid)
CSS Flexbox (Flexible Box Layout):

Conceitos do container flexível e itens flexíveis.

Propriedades de alinhamento e distribuição no eixo principal e transversal (justify-content, align-items, flex-direction, flex-wrap).

Controle individual de itens (flex-grow, flex-shrink, flex-basis, order).

CSS Grid Layout:

Conceito de malha/grade bi-dimensional.

Definição de linhas e colunas (grid-template-columns, grid-template-rows, repeat(), fr).

Espaçamento e posicionamento explícito de elementos (gap, grid-column, grid-row, grid-template-areas).

Construção de Portfólio Profissional:

Aplicação prática juntando Flexbox e Grid para construir a estrutura completa de um portfólio moderno, responsivo e publicado na web.

# JavaScript Course by CursoemVideo

The course is structured into 5 sequential modules, taking you from absolute zero to building modern and responsive layouts. Below is the breakdown of the topics covered in each module:

### Module 1: Basic Concepts and First Web Page
* **History and How the Web Works:** How the internet works, servers, domains, hosting, and the difference between HTML, CSS, and JavaScript.
* **Environment Setup:** Installing and configuring code editors (VS Code) and useful extensions.
* **HTML5 Syntax and Semantics:**
  * Basic HTML document structure (`<!DOCTYPE>`, `<html>`, `<head>`, `<body>`).
  * Paragraphs, line breaks, symbols, and emojis.
  * Heading hierarchy (`<h1>` to `<h6>`).
* **Media and Formatting:**
  * Inserting images (`<img>`), favicons, audio, and videos (internal and hosted on YouTube/Vimeo).
  * Text formatting (bold, italic, highlights, blockquotes, and source code).
  * Ordered, unordered, and definition lists.
* **Links and Anchors:** Creating internal and external links, as well as download links.
* **Introduction to CSS3:** First steps with inline, internal, and external styles.

### Module 2: Design, Colors, Typography, and Box Model
* **Web Design Fundamentals:**
  * Color psychology, harmonization, and color palette tools.
  * Color representation in CSS (Hexadecimal, RGB, HSL).
* **Typography:**
  * Font selection and using external fonts (Google Fonts and local `@font-face` files).
  * Alignment, font size, and font weight.
* **Selectors and Pseudo-classes:**
  * Selectors by class (`.`), ID (`#`), and HTML elements.
  * Using pseudo-classes like `:hover`, `:visited`, `:active`, and pseudo-elements.
* **Box Model:**
  * Concepts of `margin`, `padding`, `border`, and `outline`.
  * Difference between inline and block-level elements.
  * Grouping tags (`<main>`, `<header>`, `<nav>`, `<article>`, `<section>`, `<footer>`).
* **Practical Project:** Creating a fully styled website (Website about the history of the Android mascot).

### Module 3: Background Images, Tables, and Advanced Projects
* **Background Images and Effects:**
  * Properties of `background-image`, `background-position`, `background-repeat`, and `background-size`.
  * Parallax scrolling technique using pure CSS.
* **Tables in HTML/CSS:**
  * Proper and semantic table structure (`<table>`, `<thead>`, `<tbody>`, `<tfoot>`, `<tr>`, `<th>`, `<td>`).
  * Merging cells using `colspan` and `rowspan`.
  * Styling large tables and applying zebra striping.
  * Making tables responsive for smaller screens.
* **Practical Projects:**
  * Cordel Project (website featuring a parallax effect).
  * Building complete and dynamic tables.

### Module 4: Forms, Iframes, and Responsiveness (Mobile First)
* **Iframes (Inline Frames):**
  * Using the `<iframe>` tag and securely embedding external content.
* **Web Forms:**
  * Creating forms with the `<form>` tag.
  * Input field types (`<input>` with `text`, `password`, `email`, `number`, `date`, `color`, `range`, `file`, etc.).
  * Advanced elements: `<select>`, `<option>`, `<datalist>`, `<textarea>`, `<fieldset>`, and `<legend>`.
  * Basic HTML5 validation.
* **Responsive Design and Media Queries:**
  * Mobile First concept (developing for mobile first, then adapting for larger screens).
  * Using `@media` queries to adapt layouts to different resolutions and screen orientations.
* **Practical Project:**
  * Social Media Project (interactive menu simulating a smartphone screen with dynamic views via iframe).

### Module 5: Modern Layouts (Flexbox and CSS Grid)
* **CSS Flexbox (Flexible Box Layout):**
  * Concepts of flexible containers and flexible items.
  * Alignment and distribution properties along the main and cross axes (`justify-content`, `align-items`, `flex-direction`, `flex-wrap`).
  * Individual item control (`flex-grow`, `flex-shrink`, `flex-basis`, `order`).
* **CSS Grid Layout:**
  * Concept of two-dimensional grids.
  * Defining rows and columns (`grid-template-columns`, `grid-template-rows`, `repeat()`, `fr`).
  * Spacing and explicit element positioning (`gap`, `grid-column`, `grid-row`, `grid-template-areas`).
* **Professional Portfolio Building:**
  * Practical application combining Flexbox and Grid to build the complete structure of a modern, responsive portfolio published on the web.
